Examiner: Online Quiz & Assessment Platform

A full-stack quiz platform that lets people create, take and review quizzes in a fast, clean interface, built with Next.js on the front end and a Bun/Elysia API backed by PostgreSQL.

Project Overview

Examiner is a quiz and assessment platform built to make testing simple. It gives creators an easy way to build quizzes and gives learners a smooth, distraction-free experience when answering questions and seeing their results.

The Challenge

Many quiz tools are heavy, slow on mobile or hard to set up. The goal was a lightweight platform that loads quickly, stores results reliably and is ready to deploy without hardcoded settings or fragile configuration.

Our Approach

We split the app into a Next.js front end, a Bun/Elysia API and a PostgreSQL database running in Docker. Configuration lives in environment variables, which keeps the project clean, secure and easy to move between machines and servers.
